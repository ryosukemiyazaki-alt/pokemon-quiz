# どっちが上？ — ポケモン種族値クイズ

`index.html` をブラウザーで開くと遊べます。ビルドやインストールは不要です。

- 10問の能力比較クイズ。HP・こうげき・ぼうぎょ・とくこう・とくぼう・すばやさ、またはおまかせを選択。
- 高い方、または「同じ」を回答。回答後に数値と正解を表示。
- カントーの通常のすがた／共有シート全体を選択。
- スコア、連続正解、全問のふりかえり。設定別のベストをブラウザーに保存。
- 制限時間、ログイン、サーバーへの成績送信はありません。

## データ

出典: https://docs.google.com/spreadsheets/d/1XHgc37639sI5U1H1Wj-DQW6wfC3COjiwlztFuti4zI0/edit

「種族値リスト全」（gid=1256707327）の2026-09-22取得データを `data.js` に収録しています。シートの値をそのまま採用し、最新のゲーム公式データとの照合はしていません。シートとは自動同期しません。シートにないポケモンは出題されません。カントーの通常のすがたは図鑑番号151以下かつデータIDと図鑑番号が一致するレコードです。

名前・種族値を使用する非公式ファン制作の試作です。ドット絵はPokeAPIから読み込みます。音声素材は使用していません。Google Fontsが取得できない場合は端末の標準フォントになります。

元シートには同じデータIDを持つ異なるポケモンが含まれるため、出題の識別にはシート内の連番を使用しています。元シートの名前・数値は変更していません。現在のカントー出題対象は81件です。

## 開発

ローカルプレビュー: `node server.cjs` を実行し `http://127.0.0.1:4173` を開きます。

検証: `node --test game.test.cjs`

## ポケモンのドット絵

出題カードの画像は https://github.com/PokeAPI/sprites の標準PNGを外部読み込みします。インターネット接続が必要です。画像がない場合・取得に失敗した場合は「画像未対応」を表示し、クイズは続行できます。別のフォルムの画像には置き換えません。

`data.js` の `spriteId` はPokeAPIの `pokemon.csv` の種族番号との一致を確認しています。メガピクシーは10278、サトシゲッコウガは10117に補正しています。元シートの種族値・IDは保持しています。
